# RE-USE frontend port stage

This isolated stage implements mono reflected-padding STFT, periodic Hann
windowing, log1p magnitude and phase, and inverse-STFT reconstruction for NVIDIA
NemotronLabs RE-USE. It is not connected to a model or a user-facing backend.
The model graph, long-audio behavior, public interfaces and GPU acceptance remain open.

`reuse-frontend-reference` compares the result with independent PyTorch
`torch.stft` fixtures generated by `tools/ci-heavy/issue579_reuse/stft_reference.py`.
The 16 kHz input is the first 1,600 samples of `samples/jfk.wav`; the 44.1 kHz
input is a deterministic synthetic signal, exercising a 1,764-point FFT.
The two fixtures contain only float32 magnitude and phase arrays.

On the local CPU, the 16 kHz maximum magnitude and phase errors were 5.97e-8
and 1.91e-6; at 44.1 kHz they were 5.37e-7 and 2.0e-5. Phase error excludes
bins with reference magnitude at or below 0.01, where phase is ill-conditioned. The same
unit test passed address and undefined-behavior sanitizers. It also checks
invalid rates, short and nonfinite audio, and 44.1 kHz silence. This is bounded
frontend evidence, not a claim of end-to-end speech enhancement or GPU parity.

The inverse transform is also compared against an independent PyTorch fixture
with model-like amplitude and phase heads, including the silent-frame gate and
short tail padding. Maximum sample error was 6.6e-9. Round trips at 16 kHz and
44.1 kHz and invalid input controls are covered separately.

`reuse-dense-encoder-reference` exercises a model-free CPU reference for the
next boundary: input padding, the initial convolution, four dilated dense
layers and the final strided convolution, including instance normalization and
PReLU. All six synthetic stages are compared against independently generated
PyTorch outputs. This does not yet load the checkpoint, validate actual-model
encoder activations, or connect a dense encoder to a usable backend.

`reuse-selective-scan-reference` covers the Mamba-1 recurrent scan in isolation
against a small independent PyTorch fixture and a closed-form recurrence. It
also rejects nonfinite values, invalid shapes and aliased output buffers. The
`reuse-mamba-reference` covers a single forward block's projections, causal
depthwise convolution, scan and output projection against synthetic PyTorch
weights. Bidirectional time and frequency blocks, original-checkpoint
intermediate parity and decoded audio remain open.

The in-progress F32 converter `models/convert-reuse-to-gguf.py` pins the NVIDIA
checkpoint and config hashes, validates its model/frontend contract, and
rejects malformed or nonfinite tensors. `reuse-converter-controls` covers
synthetic F32 byte round-trips and invalid configs and tensors. The
[hosted original-checkpoint audit](https://github.com/CrispStrobe/CrispASR/actions/runs/42320524458)
compared all 1,416 converted tensors byte-for-byte with the pinned source.
No converted artifact is published or registered by this stage.
